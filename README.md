# 宇宙級靈魂轉世模擬器 (六道輪迴)

## 專案概述
一款基於佛教十法界與《楞嚴經》七趣宇宙觀的文字轉世網頁模擬器。玩家將經歷不同的「道」，透過隨機事件與關鍵抉擇，最終目標是累積慧根、超脫輪迴。

## 第一階段開發目標 (MVP)
1. **開局流程**：3題靈魂心理測試（計算初始：福報、慧根、貪、嗔、痴、隱藏修仙值）。
2. **生辰八字**：輸入出生日期作為隨機數種子。
3. **動態輪盤**：根據初始數值調整轉盤上「人道」與「畜生道」的面積大小（第一階段先實作這兩道）。
4. **兩大新手測試關卡**：
   - **人道**：按「年」推進，隨機觸發事件，可卡出隱藏「仙道」彩蛋。
   - **畜生道（肉雞、肉雞牛、肉雞豬線）**：按「天」推進（共45天），以「體重」與「靈性」為核心的極限求生。
      - **畜生道（狗、貓、鳥）**：按「月」推進，以「互動」與「靈性」為核心的極限求生。

## 核心數值（屬性點）設計
玩家初始會擁有隨機或可分配的屬性點，這些點數將決定每一世的起點和遭遇：
- 【福報值】（決定物質享受、是否出生在天道、富貴人家）
- 【定力值 / 清淨度】（決定是否能升入色界天，或在修行時不入魔）
- 【慧根 / 悟性】（決定是否能聽懂佛法、破除妄想、觸發超脫事件）
- 【嗔恨 / 貪婪 / 愚痴】（這三個是隱藏的三毒數值，太高會直接觸發惡道判定）
- 【隱藏數值】（《楞嚴經》專屬數值，專門用來修仙，數值越高，肉身越長壽）
